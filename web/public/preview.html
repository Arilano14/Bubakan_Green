BUBAKAN GREEN

Kelurahan Bubakan, Mijen

Panduan Peninjauan UI (Phase 1–4)

Simulator ini merefleksikan arsitektur Android Jetpack Compose resmi dengan tema Palette Alam Bubakan (anti-slop, kontras WCAG AA, dan tata letak botani jernih).

🔐 Pengujian Akses Role (Phase 4)

Gunakan tombol "5. Login Petugas" atau klik gembok 🔒 di pojok kanan atas layar ponsel untuk masuk sebagai PIC Lapangan atau Admin Kelurahan.

📍 Single-Shot GPS & Toleransi

Buka "7. Form Kebun (GPS)" dan klik tombol "Kunci Titik Lokasi GPS" untuk mensimulasikan pengukuran satelit dengan akurasi meter real-time.

🏛️ Alur Persetujuan Kelurahan

Buka "10. Antrean Persetujuan" untuk melihat bagaimana Admin dapat menyetujui (status PUBLISHED) atau menolak pengajuan dengan catatan revisi.

📲 Menjalankan Versi Native di Android Studio

Buka folder project ini di Android Studio, lalu tekan tombol hijau ▶ Run (Shift+F10) untuk menjalankan APK native di Emulator atau HP fisik Anda.
