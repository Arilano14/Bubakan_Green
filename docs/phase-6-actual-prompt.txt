SECTION 12 — MAP TECHNOLOGY DECISION
============================================================

Before coding, compare available approaches.

OPTION A:
Google Maps SDK for Android

OPTION B:
Google Maps Embed / WebView

OPTION C:
OpenStreetMap + Leaflet / compatible web map

OPTION D:
existing map library already present in repository

Criteria:

1. no unnecessary billing
2. no unnecessary API key
3. low dependency weight
4. multiple custom markers
5. dynamic Firestore locations
6. marker category color
7. tap marker
8. maintainable
9. responsive
10. acceptable legal/attribution requirements

DO NOT automatically choose Google Maps.

If Google Maps SDK requires billing/API key,
document that before adopting it.

If using OpenStreetMap public tiles:
must comply with OSM tile usage,
attribution,
cache,
User-Agent,
and usage policy.

Choose the simplest viable option.

SECTION 13 — RECOMMENDED DECISION RULE
============================================================

- avoids paid infrastructure
- avoids a new backend
- requires the fewest dependencies
- supports multiple dynamic markers
- works with existing Firestore locations

Do NOT choose a technology only because
it is visually familiar.
