==================================================

PIC must be able to register a new location using GPS.

Expected concept:

→ Preview coordinates on map

Do NOT implement:
- background tracking
- continuous GPS monitoring
- geofencing
- location history
- route navigation
- live tracking

unless explicitly approved later.

Use minimal location permission necessary.

==================================================
QR REQUIREMENT
==================================================

QR is intended primarily for REAL PLANTS that are actually planted
and selected as featured/physical information targets.

Do NOT generate QR for hypothetical or dummy plants.

Correct workflow:

FIELD INVENTORY
→ VERIFY ACTUAL PLANTS
→ SELECT PLANTS TO FEATURE
→ CREATE STABLE PLANT IDs
→ GENERATE QR
→ PRINT LABEL
→ FIELD TEST

QR should reference a stable plant/location identifier,
NOT contain the full plant information.

The purpose is to ensure that changing data does not require
reprinting the QR.

QR flow concept:

QR
→ HTTPS App Link
→ If app is installed:
     open BUBAKAN GREEN
     directly to relevant plant/location
→ If app is not installed:
     open lightweight web fallback
     → download APK

Do NOT create an internal QR scanner in the APK
unless there is a validated product reason later.

The default UX is:
camera / Google Lens / phone QR scanner
→ app link
→ app opens.
