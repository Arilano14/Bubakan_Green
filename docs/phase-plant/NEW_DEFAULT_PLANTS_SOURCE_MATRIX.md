# Canonical Plant Source Matrix & Botanical Validation — Bubakan Green
# Sirih, Pegagan, Kemangi & Photo Replacement Audits

Dokumentasi rujukan taksonomi botani kanonikal, nomenklatur ilmiah resmi, transliterasi Mandarin, dan verifikasi sumber data untuk 3 tanaman default baru (*Sirih*, *Pegagan*, *Kemangi*) serta verifikasi foto pengganti untuk tanaman terdaftar (*Cabai*, *Lidah Buaya*).

Rujukan Taksonomi & Farmakope Utama:
1. **Royal Botanic Gardens, Kew — Plants of the World Online (POWO)**
2. **Flora of China (Missouri Botanical Garden & Harvard University Herbaria)**
3. **Farmakope Herbal Indonesia Edisi II (Kementerian Kesehatan RI)**
4. **Balai Penelitian Tanaman Rempah dan Obat (Balittro) / Badan Litbang Pertanian**
5. **WHO Monographs on Selected Medicinal Plants**

## 3. Strict Compliance Guardrails
1. **No Artificial Placeholders**: Tidak menggunakan teks tiruan seperti *"Lorem ipsum"*, *"Informasi tanaman"*, atau *"Data akan tersedia"*.
2. **Field Removal Compliance**: Bidang metadata lama (*URL Referensi Foto*, *Fotografer*, *Lisensi Foto*, *Referensi Taksonomi Ilmiah*) tidak ditampilkan pada antarmuka input Admin.
3. **Mandarin Voice Optionality**: Field `mandarinAudioUrl` tetap bernilai `null` tanpa memicu error validasi, kegagalan simpan, ataupun exception pemutar audio.
